Darah APT setup

Confirm the signing-key fingerprint using the official release page before installing the key. Expected fingerprint 8A4BC5E1513B85AD3C9C58CACF9412C5BFA49105.

Official Darah release

curl -fLO https://citrineio.github.io/darah-eda/apt/darah-archive-keyring.gpg
gpg --show-keys --with-fingerprint darah-archive-keyring.gpg
sudo install -D -m 0644 darah-archive-keyring.gpg /etc/apt/keyrings/darah-archive-keyring.gpg
sudo tee /etc/apt/sources.list.d/darah.sources >/dev/null <<'EOF'
Types: deb
URIs: https://citrineio.github.io/darah-eda/apt/
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/darah-archive-keyring.gpg
EOF
sudo apt update
sudo apt install darah-eda

On an enrolled system, use your regular system updater or run sudo apt update followed by sudo apt install --only-upgrade darah-eda.
